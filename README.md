# E-Helper Website — Resmi Tanıtım & Özet Web Sitesi

Casper Excalibur oyuncu dizüstü bilgisayarları için geliştirilen **[E-Helper](https://github.com/berkevnl/E-Helper)** açık kaynaklı kontrol merkezinin resmi tanıtım, canlı simülasyon ve sürüm notları web sitesidir.

## 🚀 Özellikler

- **İnteraktif Donanım ve Klavye Simülatörü:** Ziyaretçilerin tarayıcı üzerinde E-Helper sistem tepsisi arayüzünü (Güç modları, fan devirleri, 3-bölge RGB klavye haritası, parlaklık) canlı test edebileceği modern simülatör.
- **Kafa Kafaya Karşılaştırma:** Resmi Casper Excalibur Control Center ile bellek, arka plan servisleri, açılış hızları ve telemetri karşılaştırma tablosu.
- **Detaylı Sürüm Geçmişi & Notları:** v1.1.1, v1.1.0, v1.0.1 ve v1.0.0 sürümlerinin tüm yenilikleri, hata düzeltmeleri ve indirme bağlantıları.
- **Çift Dil Desteği:** Tek tıkla Türkçe ve İngilizce (TR / EN) dil değişimi.
- **Çift Tema Desteği:** Gece (Stealth Dark) ve Gündüz (Crisp Light) temaları.
- **Sıfır Bağımlılık & 100/100 Performans:** Saf, optimize edilmiş HTML5, CSS3 ve Vanilla JavaScript mimarisi ile sıfır gecikmeli, anında yüklenen web deneyimi.

## 🌐 GitHub Pages ile Canlıya Alma

Bu depo doğrudan statik dosyalardan oluştuğu için GitHub Pages üzerinden anında yayınlanabilir:

1. Deponuzun **Settings** > **Pages** menüsüne gidin.
2. **Build and deployment** > **Source** kısmında `Deploy from a branch` seçin.
3. Branch olarak `main` ve klasör olarak `/ (root)` seçip **Save** deyin.
4. Siteniz saniyeler içinde `https://berkevnl.github.io/e-helper-website/` adresinde yayına girecektir.
